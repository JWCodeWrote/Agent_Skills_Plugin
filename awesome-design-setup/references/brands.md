# awesome-design-md 品牌目录

来源：https://github.com/VoltAgent/awesome-design-md
原始文件基础 URL：`https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/design-md/{brand}/DESIGN.md`

风格标签说明：
- **极简/技术感**：深色背景、等宽字体、高密度信息
- **温暖/编辑感**：暖色调、阅读优先、舒适留白
- **专业/金融感**：可信赖、俐落、严肃
- **奢华/高端感**：暗色系、强对比、精致细节
- **缤纷/产品感**：高饱和色彩、活泼、强品牌色
- **设计师感**：精致排版、动态感、创意优先
- **开发者工具感**：功能导向、数据密集、深色 IDE 风
